# 🏠 MyHomepage

HTML과 CSS로 만든 **첫 번째 온라인 이력서 페이지**입니다.

## 구성

- **프로필** – 사진과 이름
- **상세 내용**
  - 인적사항
  - 학력사항
  - 경력사항
  - 보유 스킬 (C, C++, Python, Java, HTML, CSS, JavaScript)

상단 메뉴를 누르면 해당 섹션으로 이동합니다.

## 파일 구조

```
├── index.html   # 페이지 구조
├── index.css    # 스타일
└── photo.png    # 프로필 사진
```

## 사용 기술

`HTML` `CSS`

## 실행 방법

`index.html`을 브라우저로 열면 됩니다.

> 이후 이 페이지를 발전시킨 버전이 [Time_to_Color](https://github.com/Mixx98/Time_to_Color) 입니다.
